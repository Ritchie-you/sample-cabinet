# 样品柜在线管理系统

多人在线协作管理样品柜，微信里打开链接即可使用，无需安装任何APP。

## 功能
- 三个柜子可视化网格：A1灰柜(14×5)、A2蓝柜(25×5)、小红柜(10×6)
- 点击格子录入：项目号、样品名称、入库日期、负责人、状态(在柜/借出)、备注
- 搜索高亮、操作日志（谁改了什么都有记录）
- 多人实时编辑同一份数据
- 手机微信里直接打开，适配触屏操作

## 部署上线（5分钟，免费）

### 方法一：Render（推荐，最简单）

1. 注册 https://render.com （用GitHub账号登录最快）
2. 把本项目代码推到你的GitHub仓库（或直接用Render的Deploy from GitHub）
3. 点 **New → Web Service**，连接你的GitHub仓库
4. 设置：
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - 实例类型选 **Free**
5. 点 Create Web Service，等1分钟部署完成
6. 你会得到一个网址，形如 `https://你的项目名.onrender.com`
7. 把这个链接发到微信群里，大家微信点开就能用

> 注意：Render免费版15分钟无人访问会休眠，第一次打开需要等30秒唤醒。团队用够了。

### 方法二：Railway

1. 注册 https://railway.app （用GitHub登录）
2. New Project → Deploy from GitHub repo
3. 选择本仓库，Railway会自动识别Node.js项目
4. 不需要任何配置，自动部署
5. 在Settings里生成一个公网域名，复制链接发群里

### 方法三：自己服务器

如果你有云服务器：
```bash
npm install
node server.js
# 默认端口3000，用nginx反向代理即可
```

## 使用说明
1. 第一次打开，在顶部黄色条里填自己的名字（保存时记录是谁改的）
2. 点任意格子录入样品信息
3. 搜索框输入项目号/样品名可快速定位
4. 点右上角"操作日志"可查看谁改了什么

## 不需要微信登录
这个系统不需要登录——知道链接的人就能编辑。适合内部小团队，比微信登录更省事。每次保存自动记录操作人名字。
